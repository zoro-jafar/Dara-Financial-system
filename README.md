# سیستم مدیریت مالی دارا (Dara Financial Management)

این پروژه یک سیستم جامع مدیریت مالی است که با فریم‌ورک **Django** نوشته شده است.

## ✨ امکانات پروژه:
- مدیریت هزینه‌ها (ثبت، ویرایش، جستجو و فیلتر)
- مدیریت فاکتورها و مشاهده جزئیات
- مدیریت سرمایه‌گذاری‌ها
- مدیریت حقوق و دستمزد کارکنان
- داشبورد تعاملی با نمودارهای پویا (Chart.js)
- گزارش‌های مالی (تراز آزمایشی، سود و زیان و...)
- سیستم احراز هویت (ورود، ثبت‌نام و خروج)
- پنل ادمین برای مدیریت دیتابیس

## 🛠 تکنولوژی‌های استفاده شده:
- Backend: Python, Django
- Frontend: HTML, CSS, JavaScript
- Database: SQLite
- Chart: Chart.js
- Jalali Date: django-jalali
